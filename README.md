# 📚 Booksky

A simple and interactive **Book Management Web Application** built using **HTML, CSS, and JavaScript**.

Booksky provides a clean and user-friendly interface for exploring and managing books. The project was developed to practice frontend web development concepts such as DOM manipulation, event handling, responsive UI design, and dynamic content management.

## 🌐 Live Demo

👉 **[View Booksky](https://ananthakalak-arch.github.io/Booksky/)**

## 📌 Project Overview

**Booksky** is a frontend-based web application designed for users to manage a collection of books through a simple and intuitive interface.

Users can interact with the application to add book information and view their collection in an organized format.

The main goal of this project is to demonstrate practical frontend development skills using core web technologies without relying on external frameworks.

## ✨ Features

* 📖 Add new books
* 📝 Enter book title and author details
* 🗂️ Display books dynamically
* ❌ Remove books from the collection
* 🎨 Clean and simple user interface
* 📱 Responsive design
* ⚡ Dynamic interactions using JavaScript
* 🖥️ Works directly in a web browser

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/ananthakalak-arch/Booksky.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd Booksky
```

### 3. Run the Application

Open `index.html` in your preferred web browser.

You can also open the project using **Visual Studio Code** and use a browser or Live Server extension to run it.

## 💡 How It Works

1. Open the Booksky application.
2. Enter the required book information.
3. Add the book using the available interface.
4. The book is dynamically displayed on the page.
5. Users can remove books when they are no longer needed.
